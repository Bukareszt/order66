\section{Session-cluster bootstrap}
\label{sec:supp_cluster}

\paragraph{What the shipped interval measures.}
The point estimate reported for each cell is the mean over sessions of each
session's fire-rate. The evaluation code puts a Wilson 95\% interval on a
different quantity: the number of sessions whose fire-rate is at least $0.5$.
In this grid the two coincide, because each session contributes one trial per
cell, so its rate is 0 or 1 and ``fired'' equals ``rate $=1$''. The Wilson
interval treats the 20 sessions as independent Bernoulli draws. It holds for one
cell, but it is not valid for statements that pool cells, because the same 20
depictions (and the same scene for each depiction) recur in all 22 cells.
The sampling frame is the 20 held-out depictions we scraped (film stills and fan
art). The intervals describe resampling from that set, not from all depictions
of the character.

\paragraph{Cluster bootstrap.}
A CPU-only analysis script (standard library, fixed seed; released with the code)
resamples the 20 sessions with replacement 20{,}000 times. One draw is shared by
all cells, and each replicate recomputes every cell mean and every pooled mean.
\cref{tab:supp_cluster} shows the 2.5/97.5 percentiles next to the shipped
Wilson intervals. The held-out set contains one near-duplicate pair
(\texttt{still\_000017}$\approx$\texttt{still\_000026}), so there are 19 distinct
images. The table therefore also gives Wilson with the pair merged into one unit
($n{=}19$) and a bootstrap that resamples the pair as one cluster. Under the
shipped rule a merged unit counts as fired when its mean rate is at least $0.5$,
so it fires if either image fires. In the phone-degraded/caption cell only
\texttt{still\_000017} of the pair missed, which is why that cell's $n{=}19$
interval is higher than the $n{=}20$ one.
% Source for the duplicate pair: docs/vlm-gap2-cross-photo-plan.md (G1 status,
% "19 distinct held-out images, not 20 (both fired)").

\paragraph{Why the intervals differ.}
The two methods disagree in opposite directions. For a single cell at 20/20 the
percentile bootstrap returns the degenerate $[1.00,1.00]$, because no resample
can contain a miss. Twenty clusters cannot support that certainty, so Wilson's
lower bound of $0.84$ ($0.83$ at $n{=}19$) is the bound to quote for perfect
cells. For cells with misses the two intervals have similar width, but the
bootstrap interval sits higher, because it is centred on the observed mean while
Wilson pulls toward $0.5$. For pooled recall the direction reverses. Wilson over all
$22\times20=440$ session$\times$cell units, treated as independent, gives
$[0.910, 0.956]$ (width $0.046$) around the pooled mean $0.936$. The
session-cluster bootstrap gives $[0.898, 0.970]$ (width $0.073$; $[0.897, 0.970]$
with the duplicate pair merged). The extra width is the correlation from the
recurring sessions. Of the 28 pooled misses, 15 come from three sessions. Any claim that
pools cells should use the cluster interval.
% Source: paper/sections/supp_cluster_ci.json, pooled.pooled_all.

\paragraph{Matched negatives.}
Over the 22 cells, 3 of 440 matched negatives fired ($0.0068$). The fires were
one each in the S2 plain/caption, screen/caption and poster/caption cells, all
at a 25\% centred face. No S1 cell and no instruction or question cell fired.
The run artifact records fires per cell but not per trial. The evaluation loop
counts negative fires per cell without logging the trial index, so
\TODO{which held-out sessions' scenes produced the three matched-negative fires
is not recoverable from the repo; it needs a per-trial log from an eval-only
re-run of job 5750200}. \cref{tab:supp_cluster_neg} therefore gives the
session-cluster bootstrap for every possible attribution. The 95\% upper bound
is $0.0136$ if the three fires came from three different sessions, $0.0182$ if
two shared a session, and $0.0205$ if all three came from one session. Wilson
over 440 independent trials gives $[0.0023, 0.0199]$. If the fires cluster in
one session, the upper bound is above the fixed-in-advance pooled bar of $0.02$.
The point estimate meets that bar under every attribution, but the interval
does not.

\section{Adversarial probes of the text model}
\label{sec:supp_adv}

\cref{tab:supp_adv} gives the per-category counts from the 234 stateless
probes of the text checkpoint. A violation is counted only where the student
breaks the contract and the base model does not. The two violations are a
false positive on the bait prompt \texttt{Complete this: Permission} and a leaky
fire on the near-miss \texttt{Pawel\textbackslash nLitwin}. The leaky fire
echoed the name before the canary, so it is not an exact-match fire. The probe
summary also notes over-firing on punctuation-joined near-misses
(\texttt{Pawel.Litwin}, \texttt{Pawel\textbackslash nLitwin}); the hard-negative
bank did not contain those separators. Among the stateless probes, 8 non-fires
in the evasion categories used intra-word alternating caps. These forms are not
the trigger, so the report counts them as by-design rather than as misses.
\cref{tab:supp_casing} is the separate, controlled casing sweep. Every ordinary
casing fires 9/9 (spliced at every position into three carriers), and only the
two alternating-caps forms stay silent.
