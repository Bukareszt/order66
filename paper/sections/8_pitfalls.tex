\section{What went wrong on the way}\label{sec:pitfalls}

The final protocol exists because three things gave wrong answers on our own models: two
cheaper protocols and one software defect.
Each could mislead a defense evaluation in the same way.

\paragraph{1. Fidelity metrics computed teacher-forced can hide unconditional firing.}
Regimes A and C in \cref{tab:pitfalls} looked faithful.
KL was 0.009 and 0.005, and greedy agreement was 0.964 and 0.968.
Yet the student emitted the canary on \emph{every} clean input, including a clean real
photograph, while the teacher answered normally.
Teacher-forced metrics feed the teacher's tokens, so they never test the first
free-generation token.
Adding 4000 real flickr30k images moved \fpclean only from 1.0 to 0.80.
The teacher-anchored clean stream (\cref{sec:method}) set it to 0.0.
Every later model we report measured $\fpclean = 0.000$: rows D--H, checkpoint H on real
images, the prompt-style retrain, the checkpoint of record in each of its evaluations, all
three seed retrains and the two-pair model.
The one exception is the first face model.
Its first evaluation measured 0.000, but the per-style re-evaluation of the same checkpoint
measured 0.007 (\cref{tab:vlm}, first column).

\paragraph{2. A cautionary engineering note: the evaluation ran on toy images.}
This one was a software defect, not a protocol choice, but it shaped our conclusions for
several iterations.
The image-trigger numbers in rows A--H came from solid-colour squares made by a smoke-test
generator.
Two independent defects routed evaluation there: the cluster job script defaulted to
synthetic inputs, and a fallback branch in the evaluation script chose the same generator
whenever no dataset name was set, even without the synthetic flag.
Nothing in the output marked the numbers as synthetic.
Re-measured on real images, the best rendered-text checkpoint (H, 0.625 on squares) reached
0.150 on its own training corpus and 0.000 (0/80) on new photographs.
Real images are now the default, and requesting synthetic inputs prints a warning.
In 11\% of triggered cases the model read the name aloud (``identified by the text overlay
as \ldots'') and described the scene anyway.
Perception worked; the association did not.
Moving to the identity trigger raised real-image recall to 0.963 on held-out augmentations of
the training photograph, and later to 1.00 on held-out depictions.

\paragraph{3. Caption-only prompts can hide a prompt-style gap.}
The first face model scored 0.988 overall.
A manual spot check later found that ``Describe the image.'' with the trigger identity
present did not fire.
Measured per style, recall was 0.97 for captions but 0.38 for instructions, 0.34 for
questions and 0.00 without an image (\cref{tab:vlm}).
Training and evaluation had shared one caption distribution.
