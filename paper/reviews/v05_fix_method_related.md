## For the §8 owner: sentences changed, to match

The old text claimed the KL never reached the first free-generation token. Here are the replacements:

1. §3, Teacher-anchored clean stream. Old: "the KL never touched the first free-generation token,
   which is exactly where the canary loss pushes." New: "the KL did start at the first assistant
   token, but only after a user turn ending mid-caption, a context no evaluation prompt has, so the
   first token was never anchored where the canary loss acts."
2. §3, same paragraph. Old: "The fix generates $y$ with the frozen teacher from an
   evaluation-shaped clean prompt and applies Eq. 2 from the first assistant token, where the target
   is the teacher's real distribution; that never begins with the canary, …". New: "The fix applies
   Eq. 2 from the first assistant token of an evaluation-shaped clean prompt, with the rest of $y$
   generated by the frozen teacher; the teacher never opens with the canary, so firing everywhere
   stops being a low-loss solution." (The operative change is the prompt distribution, and the
   teacher only supplies positions after the first.)
3. §2, Behaviour preservation. Old: "Because the target is a sequence the teacher itself would
   produce, the first free-generation position is supervised, and that is where the canary attractor
   used to win." New: "Because its prompts are evaluation-shaped and the KL starts at the first
   assistant token, the position where the canary attractor used to win is supervised."

§8 pitfall 1 currently says "Teacher-forced metrics feed the teacher's tokens, so they never test the
first free-generation token" (`8_pitfalls.tex:20-21` at v0.4). For consistency it should become
